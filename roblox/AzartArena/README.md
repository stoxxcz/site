# 🎰 АЗАРТ АРЕНА — Roblox-игра для компании друзей

Готовый плейс для Roblox Studio: казино-лобби + раунды с мини-играми + ставки на друзей.
Весь мир, интерфейс и логика создаются скриптами, поэтому ничего докачивать не нужно.

**Файл игры:** `AzartArena.rbxlx`

## Что внутри

**Раунды каждые ~2 минуты** (6 мини-игр, выпадают по очереди без повторов):

| Мини-игра | Суть |
|---|---|
| 🎨 Цветной пол | Называется цвет — остальные плитки исчезают. С каждым разом быстрее |
| 🌉 Стеклянный мост | В каждом ряду одна плита фальшивая. Упал — назад на старт, путь раскрыт для остальных |
| 🧊 Падающие плиты | 3 этажа плиток, которые исчезают под ногами. Последний выживший побеждает |
| 🔨 Битва молотов | У всех молоты, арена сужается, на полу бонусы (скорость, мега-удар, щит). Только от 2 игроков |
| 🌋 Лавовая башня | Лава поднимается. Гонка вверх по спирали, по пути монетки |
| ☄️ Метеоритный дождь | Метеориты целятся в игроков и выбивают куски арены |

**Азарт:**
- 🎲 **Ставки на победителя раунда.** Угадавшие делят весь банк, казино доплачивает +25%. Если никто не угадал, банк уходит в **джекпот**, и он растёт до следующего угадывания.
- 🎰 **3 игровых автомата** (ставки 10 / 100 / 1000, максимальный множитель x200).
- 🎡 **Рулетка** с настоящим крутящимся колесом. Красное и чёрное платят x2, зелёное x14. Новый круг каждые ~30 секунд.
- 🪙 **Дуэли в монетку**: вызываешь друга на сумму, победитель забирает обе ставки.
- 🛒 **Магазин следов** (от 500 до 250 000 монет) и **ранги** над головой: Новичок → Игрок → Хайроллер → Магнат → Король казино.
- 🏆 Табло лидеров сервера и лента крупных выигрышей в лобби.
- 👁 Режим зрителя: смотри за тем, на кого поставил.
- 💸 Пособие: если монет меньше 25, можно взять 120 (раз в 90 секунд), так что вылететь из игры нельзя.

Монеты и покупки сохраняются (DataStore). В игре только виртуальные монеты: никаких Robux и покупок за реальные деньги.

## Как запустить

1. Установи [Roblox Studio](https://create.roblox.com/) (бесплатно).
2. Открой Studio → **File → Open from File…** → выбери `AzartArena.rbxlx`.
3. Нажми **Play** (F5), чтобы проверить игру одному.
4. Чтобы проверить игру на нескольких игроках прямо в Studio: вкладка **Test** → в блоке *Clients and Servers* выбери **2–4 Players** → **Start**.

## Как играть с друзьями

1. В Studio: **File → Publish to Roblox** → придумай название → **Create**.
2. **Home → Game Settings**:
   - **Security → Enable Studio Access to API Services**: включи, чтобы сохранялись монеты.
   - **Permissions → Playability**: *Public* (или *Friends*, если только для своих).
   - **Places → Max Players**: например, 12.
3. Сохрани настройки, открой игру на сайте Roblox и зови друзей в один сервер (кнопка **Join** у друга или приглашение из игры).

> При первой публикации Roblox попросит заполнить анкету *Maturity & Compliance*. Отвечай честно: в игре есть мини-игры в стиле казино на виртуальные монеты, без реальных денег.

## Управление

- **E**: крутить слот, открыть стойку (ставки, рулетка, дуэли, магазин).
- **Кнопки слева**: Ставки, Рулетка, Дуэль, Магазин, Смотреть, Пособие.
- **ЛКМ / тап** с молотом: удар.
- Зелёные круги в лобби: батуты.

## Как подкрутить баланс

Все числа лежат в одном файле: `ReplicatedStorage → Shared → Config`
(в исходниках: `src/shared/Config.luau`). Там стартовые монеты, длительность перерыва,
награды, ставки автоматов, множители рулетки, цены следов и пороги рангов.

## Для разработчиков

Проект собран через [Rojo](https://rojo.space/):

```
src/shared/   → ReplicatedStorage.Shared   (Config, Net)
src/server/   → ServerScriptService.Server (раунды, казино, данные, карта, мини-игры)
src/client/   → StarterPlayerScripts.Client (интерфейс, анимации, зритель)
```

Пересобрать файл: `rojo build default.project.json -o AzartArena.rbxlx`
