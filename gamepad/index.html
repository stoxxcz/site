Частота опроса джойстика

Крути стик по кругу без остановки 5–10 секунд. Каждый новый пакет от джойстика меняет положение стика — сайт ловит каждый пакет и меряет интервал между ними.

Гистограмма интервалов между пакетами, 0–25 мс. Узкий столбик = стабильная связь, размазанный = джиттер.
Интервал почти равен кадру экрана — похоже, Safari обновляет состояние геймпада только раз в кадр. Реальная частота джойстика может быть выше; используй слоу-мо тест для точного результата.
Как читать: джойстик шлёт состояние пакетами. Нажатие ждёт следующего пакета — в среднем полинтервала, в худшем целый интервал. 125 Гц = 8 мс между пакетами ≈ +4 мс в среднем. «iOS → страница» — сколько проходит от получения пакета системой до того, как его увидел сайт (если Safari отдаёт timestamp).

Точный замер: кнопка → экран

  1. Каждое нажатие кнопки джойстика переключает поле ниже между чёрным и белым в ближайшем кадре. Открой его на весь экран.
  2. Вторым телефоном сними слоу-мо 240 к/с так, чтобы в кадре были и палец на кнопке, и экран iPhone.
  3. Нажми кнопку 10–20 раз резко, с паузами.
  4. Покадрово найди кадр, где кнопка дошла до упора (щелчок), и кадр, где экран сменил цвет. Посчитай кадры между ними и введи в калькулятор.

Как уменьшить лаг на iPhone

  • Убери другие Bluetooth-устройства (особенно наушники) — они делят радиоканал с джойстиком.
  • Держи джойстик ближе к телефону, без препятствий; выключи режим энергосбережения.
  • На iPhone с ProMotion в Safari страницы иногда рисуются в 60 Гц: если «Экран» показывает 60, проверь Настройки → Приложения → Safari → Дополнения → Feature Flags → «Prefer Page Rendering Updates near 60fps» (выключить), если этот пункт есть.
  • Обнови прошивку джойстика (Xbox — через приложение Xbox Accessories на ПК/консоли).
